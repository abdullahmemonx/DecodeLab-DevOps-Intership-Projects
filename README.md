# DevOps Internship Projects

This repository contains the projects I completed during my DevOps internship at Decode Labs. Each project focuses on learning and practicing fundamental DevOps tools, workflows, and concepts through hands-on tasks.

## Projects

### Project 1: Linux & Command Line Basics 

**Goal:** Learn essential Linux commands used in DevOps environments.

**What I Practiced:**
- Navigating the Linux file system
- Creating and managing files and directories
- Using commands such as `ls`, `cd`, `mkdir`, `cat`, and `rm`
- Understanding directory structures
- Working with the terminal in Ubuntu using WSL

**Key Skills:** Linux fundamentals, command-line operations, file management

### Project 2: Version Control with Git

**Goal:** Understand how Git and GitHub help manage code and track changes.

**What I Practiced:**
- Checking repository status with `git status`
- Staging changes using `git add`
- Saving changes with `git commit`
- Viewing commit history with `git log`
- Pushing commits to GitHub using `git push`
- Understanding the basic Git workflow

**Key Skills:** Git, GitHub, version control, commit history

### Project 3: CI/CD Pipeline Basics

**Goal:** Understand how code changes can trigger automated workflows.

**What I Practiced:**
- Creating a GitHub Actions workflow
- Writing a workflow configuration using YAML
- Automating a simple Python test
- Running a Python application through the workflow
- Understanding workflow triggers, jobs, and steps

**Tools:** GitHub Actions, Python, YAML

**Key Skills:** Continuous Integration (CI), automation, testing, pipeline stages

### Project 4: Containerization with Docker

**Goal:** Learn how to package and run an application inside a Docker container.

**Planned Tasks:**
- Creating a Dockerfile
- Building a Docker image
- Running a container locally
- Understanding the difference between images and containers

**Tools:** Docker, Python

**Key Skills:** Containerization, Docker fundamentals, application packaging

*Note: The Docker setup and execution steps are still in progress.*

## Tools & Technologies

- **Programming Language:** Python
